# Issue 工作属性显示负责 Agent

- 目标是在 Issue 详情的「阶段」下显示当前 Issue 已确认领取的具名 Owner，首次未领取（包括预留和已投递）显示「未领取」。子 Issue 不使用父级归属。
- 在现有 Issue 概览读事务中，从该 Issue 的已接受分配获取最近的具名 Agent。等待、无活跃 Run 及同一归属接续时不因阶段变化或新的预留清除名字。只读既有事实，不从 Run、候选配置或时间线文本推断，不变更领取、调度或存储格式。
- Web 复用桌面侧栏及移动端工作属性，确认空值、字段顺序、父子各自 Owner 及窄屏显示。使用真实 Server、Runner 和固定 App Server fixture 验证预留到确认、等待、接续及父子区别，使用项目 Playwright 测试生成两种布局的实际页面截图。
- 定向运行 Rust 和 Web 检查，从当前分支快进推送到 `origin/main` 并核对完整 SHA。截图随交付发布，不部署。
