# 全局 Token 用量

本文记录最初的 Issue 全局投影。现行根页总计和来源见 [全系统 Agent 请求用量](system-agent-token-usage.md)。

## 目标和边界

- 在桌面资源、手机「更多」加入同级的「Token 用量」入口，保留可直接访问的 `/token-usage` 和现有 Issue 详情用量入口。
- 仅展示已归属 Issue 的 Token 和已开始 Run 的观测覆盖。区分显式零、未观测、字段缺失和部分覆盖。明确已观测不等于完整。
- 逐页列出所有顶层 Issue，不限状态。展开只读该节点的一页直接子级，列出直属与含所有后代的值，并用正式 Issue 链接进入详情。
- 本次止于远端 `main`。不部署、不运行生产回溯、不新增统计维度或采集来源。

## 实现

- 复用既有 `TokenBreakdown` 与 Issue 直属/子树投影。全局单行投影由直属差量归并，每个 Run 的贡献只归属一个 Issue。一次 schema 迁移仅以现有直属投影初始化全局行，不读取 Run、请求或 rollout。显式重算在已分批写入的 shadow 数据上维护对应汇总，并与新 Issue 投影原子发布。
- Web 与 `tend token-usage overview [--parent ID|#NUMBER] [--before CURSOR]` 共用只读 `GET /api/v1/token-usage`。根页带全局汇总，`parent` 仅返回指定 Issue 的直接子级。每页最多 30 行，通过父边、来源顺序和 Issue ID 的组合索引做键集分页。请求不轮询、不主动加载未展开子级，SQL 批量读取同页的身份、直属、子树和展开提示。
- 沿用资源导航、用量卡片、金额字段格式和覆盖提示。页面提供按需展开、分页与失败后重试。

## 读取契约

- `GET /api/v1/token-usage` 返回 `total`、`issues`、`next_before`。传 `parent`（UUID 或短编号）时不返回 `total`，`issues` 只含直接子级。每行返回 `issue_id`、`number`、`title`、`direct`、`subtree` 和 `has_children`。用 `next_before` 和原 `parent` 读取下一页，`null` 表示末页。
- 每页对同一数据库快照读取。不同页或不同分支是各自读取时的最新数据，页面不会自动轮询；刷新重新读取首页。根页固定读取一个全局行和一个分页查询。分页索引先选最多 31 个同级候选，再批量连接编号及两份用量投影，并用父边索引探测是否有直接子级。
- 保留原 [Issue 用量字段与覆盖契约](issue-token-usage.md#读写契约与已知限制)。聚合数用十进制字符串，`"0"` 是显式零，`null` 不代表未消费。已观测 Run 只说明至少一条有效请求已入账，不保证其余请求或尾部完整。
- Server schema 44 在首次升级时以现有直属投影初始化全局行。旧 Server 二进制不能直接打开升级后的库。该迁移不读原始用量，也不会创建回溯任务。

## 验证

- 存储验证空库、精确大数、零与缺字段、父/子/孙及多个根、重复及冲突撤销、旧版汇总迁移、显式重算及并发发布。检查分页查询计划和页界，确保只走投影、无跨页排序或逐节点 SQL。
- 隔离真实 Server/Runner 验证 CLI 与 HTTP 相同、覆盖和去重、Cookie 鉴权、短编号、分页和现有 Issue 用量回归。用 Playwright 对桌面和手机验证资源导航、登录后直达及刷新、展开、进入 Issue、加载和窄屏效果，提供最终渲染图。
- 合入前定向验证实际候选并核对最新 `main`，合入后核对远端 SHA。
