# 历史请求模型归属与 OpenRouter 费用估算

## 目标和边界

- 以该请求执行时所选的原生模型为正常分组和估价依据。只在原生证据能绑定具体请求并确认实际型号时校正。不能把不带响应身份的回合级改路由通知套给后续请求。现有 Agent 配置不参与历史归属。
- 同一有效型号只显示一行，已确认的 OpenRouter 精确标识及别名使用同一价格和分组。来源在展开详情中显示。不按近似名称或相近型号套用费率。
- 每次请求先确定非缓存输入、缓存读写、输出及费率档，再汇总。明确使用 OpenRouter 公示价对已上报用量估算，不是实际账单。有计量或费率缺口则只报可估算部分，无报价时不记为零。

## 实施

1. 使用现有原生回读及同步。逐请求的所选模型细于同回合上下文，明确的逐响应型号可以校正。来源和用量沿现有去重与冲突路径结算。
2. 持久投影为请求模型补上逐档收费项和用量。一次性从 Server 已保存请求中补齐旧投影所缺的模型小计，保留旧请求账本、覆盖分母和价格口径，按原直属、祖先、全局及系统来源索引更新。读取仍只消费小计，不扫描请求、原件或网络价格。尚无模型证据的旧请求继续用现有原生回填。
3. 因费率缺失、条件不支持或计量不全而未知时共享可读文案。全局和 Issue 直属、含后代共用模型行和计价逻辑。

## 验收及停点

- 对 #131 仅读取归属、计量和估价所需证据。用替换了身份的隔离样例独立逐请求算价，并对照升级、回填、重建、直属/子树/全局 API 及浏览器渲染。检查同模型不拆行、确切改路由、未知、各价格档及计量缺口。
- 运行定向 Rust、回环及 Web 测试。交付实际桌面与手机渲染图和完整远端 main SHA。合入为终点，不部署，也不写生产用量或操作 #131。

## 按调用来源

全局页的每个来源用独立折叠区显示该来源已经投影的同一模型明细，包括 Issue、主 Chat Router、讨论回复、讨论转交总结、隔离转交接收和飞书研判。零请求可以展开查看无数据，不显示零费用。展开不新增网络请求。隔离回环用同一个 Server 来源的多个模型核对金额和归并，并提供 390px 源码渲染图。

## 独立审阅后的补充

- 旧解析器曾用未知标记替代无响应身份的改路由警告或格式错误的实际型号字段。新版原生回读同时提供可核验的旧占位成因，允许在同键且兼容的计量下补证。真正观测到的同级模型冲突仍保留，旧根回合快照字节不变。
- Issue 与 Server 来源共享原生请求键时，仍由 Issue 独占计量。合并两侧相容的模型证据，不改变任何一侧的账本。两侧迟到、冲突、撤回及重建都从相同证据推导小计；新迁移也对已有重叠做同样核对。普通 GET 不参与。

复审覆盖同键重复记录。旧占位的成因作为请求事实独立保留，不随证据强度切换丢失。新版实时和历史证据在入账合并时共用价格快照的精确别名判定，旧根回合模式仍按旧字节生成快照。

兼容旧占位时，把暂缓归属的原因、已确认原因可解除的证据、以及实际观测到的型号分开保存。旧占位可暂时遮住显示型号，但不能删除同键已收到的有效型号。用交错回传和重建覆盖原件、旧占位、实时型号及其重放。
