# 将新建讨论移到桌面导航行

## 目标与边界

- 将完整桌面侧栏（≥1024px）中「讨论」下方的整行主按钮换成导航右侧始终可见的加号。链接只打开讨论首页，加号以「新建讨论」为可访问名称，只新建空白讨论。保留原生键盘操作、创建错误提示和请求幂等行为。
- 加号使用独立的 40×40 CSS px 点击区，和既有 40px 导航行对齐，不叠在链接上。窄窗图标栏与手机继续在讨论目录上提供原有的新建按钮。
- 不改最近讨论列表和选中规则、归档和恢复、讨论目录或「带入讨论」的创建行为。不改路由、API、存储和 CLI。交付止于合入，不部署，不使用线上讨论或真实模型。

## 实施与验证

1. 在全局桌面导航中把「讨论」链接与新建按钮并列放置，复用现有创建流程，移除最近讨论前的旧按钮。
2. 用临时 SQLite 和 App Server fixture 启动实际 Server，运行讨论 Web 验收。检查按钮与链接的独立性、鼠标和键盘创建、焦点与悬停、多个未命名讨论的唯一选中态，以及归档和恢复前后的列表与原讨论。手机用触控验证底部导航和目录创建，检查无横向溢出。
3. 运行 Web 类型、lint、格式、单测和构建，保存 1440×960 桌面与 390×844 手机的实测截图，核对合入后的远端 main。
