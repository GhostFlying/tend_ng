# 紧凑展示 Token 用量与估算

## 目标与边界

继续 #154 已合入的按原请求未计价展示。只改 Web 展示和验收，不修改原生用量、估算价格、金额精度、API、请求级覆盖和去重。交付到远端 main，附实际页面的 1440px 和 390px 渲染，不触发部署。

## 实现

- 全局和 Issue 摘要将已上报总 Token 与估算费用并列，第二行集中显示已识别及真正未计价的请求数。统计口径默认收起，展开可见精确原生字段、费用依据和用量覆盖。全局覆盖分母明确只统计 Issue Run，各系统来源分别保留自己的回合分母。
- 模型、调用来源、Issue 树及子树列表呈现紧凑的输入（其中缓存读取）、输出、费用和请求数。只用原生输入值，缓存读取按已记录部分展示，缺报不当零。缓存写入、推理输出、来源覆盖、模型依据、价格快照、原始分项及缺项说明继续可查，不重复相加。无需展开的行保留精确 Token，采用短单位的行能展开查看精确值。
- 估算金额按十进制字符串统一四舍五入至一位小数，用 `<$0.1` 显示会舍入到零的正数，用 `$0.0` 显示真正的零。无可用金额与无请求可区分。费率是单价依据，详情继续保留快照原始精度。

## 验证

- Web 类型、lint、格式、测试及构建。覆盖金额舍入边界和 Token 精度。
- 用真实隔离 Server、已有 #131 口径样例（52 笔，原始金额 $1.0942952）和四条 Feishu 未计价样例，验证总体、来源、两种 Issue 范围、单模型及详情，不向线上写入。
- 1440px 和 390px Chromium 实渲，检查统计口径、展开精确值、缺报/零值、无横向滚动及原有懒加载行为。验证通过后按仓库门禁推送并核对完整远端 SHA。
